Listen im HTML

In diesem Abschnitt kann ich alles über verschiedene Listen nachlesen. HTML kennt:
<ol> (sortierte Listen), <ul> (unsortierten Listen) und <dl> (beschreibenden Listen).

1. Wann nutzen wir welche Liste?

  • <ol>: Wenn die Reihenfolge wichtig ist (z.B.: Rangliste, Anleitung, Rezept)
  • <ul>: Wenn die Reihefolge egal ist (z.B.: Stichpunkte, Einkaufsliste, To-Do Liste)
  • <dl>: Für Begriffe mit Erklärungen (z.B.: Glossar, FAQ, Wörterbuch)

2. Sortierte Liste (<ol>)

Eine sortierte Liste nummeriert die Einträge automatisch.

Beispiel (Inhaltsverzeichnis):

  1. Grundaufbau eines Links
  2. Das Attribut href
  3. Link in einem neuen Tag öffnen
  4. E-Mail und Telefon Links
  5. Interne Links (Sprungmarken)

Wichtige Attribute

  • type: 1, A, a, I, i
  • start: Startwert festlegen
  • reversed: Nummerierung umkehren

Beispiel (Tiere):

  1. Hund
  2. Katze
  3. Kuh
  4. Meerschweinchen
  5. Pinguin
  1. Hund
  2. Katze
  3. Kuh
  4. Meerschweinchen
  5. Pinguin
  1. Hund
  2. Katze
  3. Kuh
  4. Meerschweinchen
  5. Pinguin

3. Unsortierte Liste (<ul>)

Eine unsortierte Liste stellt Aufzählungen dar, bei der die Reihenfolge egal ist.

Beispiel (Städte):

  • München
  • Rom
  • Nürnberg

Wichtige Attribute

  • type: none, circle, square

Beispiel (Städte):

  • Madrid
  • Bangkok
  • London
  • Madrid
  • Bangkok
  • London
  • Madrid
  • Bangkok
  • London

4. Beschreibende Listen (<dl> = Description List)

Eine beschreibende Liste besteht aus: <dt> (Term = Begriff) und <dd> (Description = Beschreibung).

Besipiel (Begriffe aus der IT):

HTML
Auszeichnungssprache zur Strukturierung von Webseiten.
CSS
Sprache für das Design und Layout der Webseite.

Mehrere Beschreibungen für einen Begriff

Dackel
Hunderasse
Gilt als schlau, lernfähig und stur.

5. Verschachtelten Listem

Listen können in anderen Listen eingebettet werden (Bsp.: Menüs und Kategorien).

Beispiel (Elektro Geräte):

  • Produkte
    1. Handys
      • Androids
      • iOS

Anleitung: Verschachtelte Listen in HTML

  1. Erstelle zuerst eine normale Liste mit <ul> oder <ol>
  2. Lege einen Listeneintrag mit <li> an
  3. Schreibe den Text für den Haupteintrag in dieses <li>
  4. Öffne innerhalb desselben <li> eine neue Liste (<ul> oder <ol>)
  5. Lege in dieser neuen Liste die Unterpunkte mit <li> an
  6. Schließe zuerst die Unterliste und danach das äußere <li>
