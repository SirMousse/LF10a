CSS Farbveräufe (Gradients)

Mit CSS kannst du Farbverläufe als Hintergrund verwenden. Farbverläufe sind keine Bilder, sondern werden direkt in CSS erzeugt.

Die wichtigsten Farbverläufe:

  1. Linear Gradient = Verlauf in eine Richtung
  2. Radial Gradient = Verlauf von der Mitte nach außen
  3. Conic Gradient = kreisförmiger Verlauf

1. Linear Gradient linear-gradient

Ein linearer Verlauf, geht in eine Richtung (z.B.: von oben nach unten).

linear-gradient (oben nach unten) 
                    
                        .linear-gradient{
                            background: linear-gradient(#00a8ff, crimson);
                        }

                        -> #00a8ff = obere Farbe des Farbverlaufes
                        -> crimson = untere Farbe des Farbevrlaufes

Du kannst auch eine Richtung angeben:

linear-gradient (nach links) 
                    
                        .linear-direction{
                            background: linear-gradient(to left, #6465a5, #f05837);
                        }

                        -> #6465a5 -> ist die erste Farbe und liegt rechts
                        -> #f05837 -> zweite Farbe und liegt links 
                        -> nach "to" kommt die Richtung, in die es Verlaufen soll

Wir können auch einen Winkel benutzen:

linear-gradient(350deg) 
                    
                        .linear-angle{
                            background: linear-gradient(350deg, #00743f, #f2a104);
                        }

                        -> zahl+deg = gibt den Winkel an, der genutzt werden soll

2. Radial Gradient (radial-gradient)

Der Farbverlauf geht von der Mitte nach außen (kreisförmig).

radial-gradient (Standard) 
                    
                        .radial-basic{
                            background: radial-gradient(circle, #c0334d, #f1931b);
                        }

                        -> circle wel es kreisförmig sein soll

Du kannst die Form beeinflussen:

radial-gradient (ellipse) 
                    
                        .radial-ellipse{
                            background: radial-gradient(ellipse, #212027, #f22f08);
                        }

                        -> ellipse weil es ellipsenförmig ist

Du kannst den Mittelpunkt verschieben:

radial-gradient (verschiebung Mittelpunkt oben Links) 
                    
                        .radial-move{
                            background: radial-gradient(circle at top left, #8e3ccb, #87c830);
                        }

                        -> #8e3ccb = hier beginnt der Kreis in der oberen linken Ecke (1/4 Kreis ist sichtbar)

3. Conic Gradient (conic-gradient)

Ein conic-gradient ist ein kreisförmiger Verlauf um einen Mittelpunkt. Er eignet sich gut für z.B.: Diagramme und Deko.

conic-gradient (Standard) 
                    
                        .conic-basic{
                            background: conic-gradient(#003d73, #1ecfd6, #edd170, #c05640);
                        }

4. Mehrere Farben und Farbstopps

Du kannst mehr als nur zwei Farben benutzen und auch Prozentwerte (Stopps) angeben.

Mehrere Farbstopps 
                    
                        .linear-stopps{
                            background: linear-gradient(to right,
                                #8a8604 0%,
                                #383140 50%,
                                #cac7d7 100%);
                        }
